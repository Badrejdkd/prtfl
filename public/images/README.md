# Images du portfolio

Déposez les images ici avec EXACTEMENT ces noms (ou changez les chemins dans `src/data/portfolio.ts`).
Tant qu'une image manque, un cadre en pointillés s'affiche à sa place.

| Fichier | Emplacement | Format conseillé |
|---|---|---|
| `profile.jpg` | Carte de visite (hero) — déjà ajoutée, extraite du CV | 4:5, 800 x 1000 px pour plus de netteté |
| `logos/adii.png` | Logo ADII | carré, 256 x 256 px |
| `logos/raznet.png` | Logo RAZNET | carré, 256 x 256 px |
| `logos/ai-system.png` | Logo AI SYSTEM | carré, 256 x 256 px |
| `projects/assistant-juridique.jpg` | Projet « Assistant juridique intelligent » | 16:9, 1600 x 900 px |
| `projects/multi-agents-medical.jpg` | Projet « Système multi-agents médical » | 16:9 |
| `projects/offres-emploi.jpg` | Projet « Analyse des offres d'emploi » | 16:9 |
| `projects/reseaux-criminels.jpg` | Projet « Analyse de réseaux criminels » | 16:9 |

Formats acceptés : .jpg, .png, .webp (adaptez l'extension dans `portfolio.ts`).
Pour masquer les cadres vides : `showImagePlaceholders = false` dans `portfolio.ts`.
